# Python Programming Exercises

A collection of Python lab exercises for a fundamentals of programming course.

## Repository layout

Exercises are organized by lab folders. The original folder names are kept so they continue to match the course materials.

## Run an exercise

Use Python 3 to run an individual exercise from the repository root:

```sh
python3 path/to/exercise.py
```

This repository is a learning archive, not an installable Python package.
