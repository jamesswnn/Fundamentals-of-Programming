## Digit Extraction

จงเขียนโปรแกรมเพื่อหาจำนวนหลัก ตัวเลขหลักแรก ตัวเลขหลักสุดท้าย และผลรวมของเลขหลักแรกและหลักสุดท้ายของ input `x` โดยสามารถเลือกได้ว่าจะใช้ **for** หรือ **while** loop ในการแก้ปัญหานี้

**Hint:** นักศึกษาสามารถใช้ operator `//` เพื่อหาผลหารโดยตัดทศนิยม/เศษออก

**หมายเหตุ:** นักศึกษาสามารถสมมติได้ว่าผู้ใช้จะ input เป็นตัวเลขจำนวนเต็มตั้งแต่ 0 ขึ้นไปเท่านั้น 
<hr>

**ตัวอย่างที่ 1:**

**Input:** `x=123456`
```
123456
```
**Expected output:** หลังจากคำนวณแล้ว โปรแกรมจะแสดงผลลัพธ์ดังนี้ โดย 
* 6 คือ จำนวนหลักของตัวเลข (123456 มีทั้งหมด 6 หลัก)
* 1 คือ ตัวเลขหลักแรก (123456 ขึ้นต้นด้วย 1)
* 6 คือ ตัวเลขหลักสุดท้าย (123456 ลงท้ายด้วย 6)
* 7 (1+6) คือ ผลรวมของตัวเลขหลักแรกและหลักสุดท้าย
```
6 1 6 7
```
<hr>

**ตัวอย่างที่ 2:**

**Input:** `x=5810230`
```
5810230
```
**Expected output:** หลังจากคำนวณแล้ว โปรแกรมจะแสดงผลลัพธ์ดังนี้ โดย 
* 7 คือ จำนวนหลักของตัวเลข 
* 5 คือ ตัวเลขหลักแรก 
* 0 คือ ตัวเลขหลักสุดท้าย
* 5 (5+0) คือ ผลรวมของตัวเลขหลักแรกและหลักสุดท้าย
```
7 5 0 5
```
<hr>

**ตัวอย่างที่ 2:**

**Input:** `x=2`
```
2
```
**Expected output:** หลังจากคำนวณแล้ว โปรแกรมจะแสดงผลลัพธ์ดังนี้ โดย 
* 1 คือ จำนวนหลักของตัวเลข 
* 2 เป็นทั้งตัวเลขหลักแรกและหลักสุดท้าย
* 4 (2+2)   คือ ผลรวมของตัวเลขหลักแรกและหลักสุดท้าย
```
1 2 2 4
```
