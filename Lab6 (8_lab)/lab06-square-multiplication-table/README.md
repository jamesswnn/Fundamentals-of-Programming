## Square Multiplication Table

จงเขียนโปรแกรมที่รับตัวเลขจำนวนเต็มไม่ติดลบ `n` จากนั้นแสดงผลลัพธ์การคูณตัวเลขเดียวกัน (multiplication of the same number) โดยเริ่มตั้งแต่ `0 X 0` ไปจนถึง `n X n` ตามลำดับ

**หมายเหตุ:** ผลคูณของ `i X i` มีค่าเท่ากับ `i ** 2` (i ยกกำลังสอง)

รูปแบบผลลัพธ์แต่ละบรรทัด:
```
i X i = ผลคูณ
```
<hr>

**ตัวอย่างที่ 1:**
**Input:** `n=4`
```
4
```
**Expected output:** โปรแกรมจะแสดงผลลัพธ์ดังต่อไปนี้
```
0 X 0 = 0
1 X 1 = 1
2 X 2 = 4
3 X 3 = 9
4 X 4 = 16
```
<hr>

**ตัวอย่างที่ 2:**
**Input:** `n=2`
```
2
```
**Expected output:** โปรแกรมจะแสดงผลลัพธ์ดังต่อไปนี้
```
0 X 0 = 0
1 X 1 = 1
2 X 2 = 4
```
