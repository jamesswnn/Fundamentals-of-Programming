## Create Sets of Travelling Cities

จงเขียนโปรแกรมเพื่อเก็บข้อมูลของนักท่องเที่ยวในแต่ละเมืองเพื่อใช้ในการค้นหารายชื่อของนักท่องเที่ยวซึ่งเดินทาง 1 เมืองขึ้นไป

### การเก็บข้อมูล

โปรแกรมใช้ **loop** เป็นจำนวน `num1` รอบ ในการเก็บชื่อเมืองสถานที่ท่องเที่ยว เพื่อมาใช้เป็น key ใน dictionary `cities`

และในแต่ละเมือง ให้ใช้ **loop** เป็นจำนวน `num2` รอบ ในการเก็บรายชื่อของนักท่องเที่ยวที่เคยไปเมืองนั้นๆ ซึ่งเก็บในรูปแบบ set มาใช้เป็น value ใน dictionary `cities`

โดยการเก็บข้อมูล จะมีลักษณะดังต่อไปนี้

```
cities {Dictionary}
{
    city_1 {Set}: {traveller_1, traveller_2, ...},
    city_2 {Set}: {traveller_2, traveller_3, ...},
    city_3 {Set}: {traveller_1, traveller_3, ...},
}
```
### การค้นหาข้อมูล และการแสดงผล

โปรแกรมจะใช้ **loop** เป็นจำนวน `num3` รอบ เพื่อรับรายชื่อของเมืองสถานที่ท่องเที่ยวอีกครั้ง

จากนั้นโปรแกรมจะคำนวณและแสดงผลดังต่อไปนี้

* print รายชื่อนักท่องเที่ยวที่เคยไปเมืองใดเมืองหนึ่ง **อย่างน้อย 1 เมือง** ในลูปที่ 3
* print รายชื่อนักท่องเที่ยวที่เคยไป **ครบทุกเมือง** ในลูปที่ 3
* รายชื่อของนักท่องเที่ยวจะแสดงผลตามลำดับตัวอักษร โดยนักศึกษาสามารถใช้คำสั่ง `sorted(list)` เพื่อเรียงลำดับข้อมูลใน list ได้
* หากไม่มีนักท่องเที่ยวที่เข้าเงื่อนไขข้างต้น ให้ print Not Found
