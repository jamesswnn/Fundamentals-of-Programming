## Sum Study Hours From The Diary
จงเขียนโปรแกรมซึ่งใช้ **loop** ในการ
รับข้อมูลที่เป็น string มาใส่ list `key_list` และรับข้อมูลที่เป็น float มาใส่ list `value_list` เป็นจำนวน `num` รอบ 

หลังจากที่ list ทั้งสองมีข้องมูลที่ใส่โดยผู้ใช้แล้ว โปรแกรมจะทำการสร้าง dictionary โดยข้อมูลใน `key_list` จะถูกใช้เป็น key และข้อมูลใน   `value_list` จะถูกใช้เป็น value

จากนั้นโปรแกรมจะคำนวณและแสดงผลดังต่อไปนี้

* print ข้อมูลใน dictionary
* หาผลรวมของ value ใน dictionary และแสดงผลด้วยทศนิยม 1 ตำแหน่ง โดยสามารถใช้ round(data, 1)

**หมายเหตุ:** โปรแกรมนี้ถูกสร้างขึ้นมาเพื่อเก็บวัน (string มาใส่ list `key_list`)  และจำนวนชั่วโมงในแต่ละวันที่นักเรียนอ่านหนังสือ (float มาใส่ list `value_list`)

<hr>

**ตัวอย่างที่ 1:**
**Input:** ผู้ใช้ input `num=3`
```
3
010121
7.5
020121
1.5
030221
1.0
```
**Expected output:** หลังจากรับ input ทั้งหมดแล้วไปเก็บใน list ทั้งสองแล้ว โปรแกรมจะสร้างและแสดง dictionary และข้อมูลผมรวมของจำนวนชั่วโมงในแต่ละวันที่นักเรียนอ่านหนังสือ ดังนี้
```
{'010121': 7.5, '020121': 1.5, '030221': 1.0}
10.0
```
