## Magic Function Retrival with Tuple and Dictionary

ให้นักศึกษาจินตนาการว่ามี `magic_function` ซึ่งใช้เวลาในการประมวลผลนาน
จงเขียนโปรแกรมเพื่อเก็บค่าจาก `magic_function` เพื่อใช้ในการเรียกข้อมูลในภายหลัง

### การเก็บข้อมูล

โปรแกรมใช้ **loop** เป็นจำนวน `num1` รอบ ในการเก็บผลลัพธ์จาก `magic_function` ที่ได้ประมวลผลล่วงหน้ามาแล้ว
โดยผลลัพธ์ของ `magic_function` จะถูกรับมาในรูปแบบตัวเลข 3 จำนวน
1. จำนวนทศนิยม 2 ตำแหน่ง ระบุตำแหน่งบนแกน x
2. จำนวนทศนิยม 2 ตำแหน่ง ระบุตำแหน่งบนแกน y
3. จำนวนทศนิยม 2 ตำแหน่ง ระบุผลลัพธ์ของ `magic_function`
โดยข้อมูลทั้ง 3 จะถูกแยกจากกันด้วยการขึ้นบรรทัดใหม่

จากนั้น สร้าง Tuple `(x,y)` เพื่อใช้เป็น key สำหรับ dictionary `magic_results` และใช้ผลลัพธ์ของ `magic_function` เป็น value

### การค้นหาข้อมูล และการแสดงผล
โปรแกรมจะใช้ **loop** เป็นจำนวน `num2` รอบ ในแต่ละรอบจะรับค่ามาในรูปแบบตัวเลข 3 จำนวน
1. จำนวนทศนิยม 2 ตำแหน่ง ระบุตำแหน่งบนแกน x
2. จำนวนทศนิยม 2 ตำแหน่ง ระบุตำแหน่งบนแกน y
3. จำนวนทศนิยม 2 ตำแหน่ง z

ในแต่ละชุดตำแหน่ง และค่าทศนิยมให้แสดงผลดังนี้
* print "Correct" เมื่อค่าทศนิยม z **ตรงกับ** ผลลัพธ์จาก `magic_function` ใน dictionary
* print "Incorrect" เมื่อค่าทศนิยม z **ไม่ตรงกับ** ผลลัพธ์จาก `magic_function` ใน dictionary
* print "Magic Required!!" เมื่อตำแหน่ง `(x,y)` ไม่อยู่ในการประมวลผลล่วงหน้า (ไม่มีตำแหน่งดังกล่าวใน `magic_results`)
