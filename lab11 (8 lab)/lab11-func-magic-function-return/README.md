## Magic Function Return

ในชั่วโมงปฏิบัติก่อนหน้า นักศึกษาได้พบกับโจทย์ `Magic Function Retreieval` ไปแล้ว
ในครั้งนี้ นักศึกษาจะเป็นผู้เขียนฟังก์ชั่น `magic_function` เพื่่อพัฒนาโปรแกรมให้สมบูรณ์

### การทำงานของ Magic Function

`magic_function` จะรับข้อมูลมาในรูปแบบทศนิยม 2 จำนวน 
1. จำนวนทศนิยม 2 ตำแหน่ง ในชื่อ `x1` ระบุตำแหน่งบนแกน x
2. จำนวนทศนิยม 2 ตำแหน่ง ในชื่อ `y1` ระบุตำแหน่งบนแกน y

จากนั้นฟังก์ชั่นจะคำนวนระยะห่างระหว่าง (x1,y1) กับตำแหน่ง (0.2400, 1.7456) โดยใช้สูตรคำนวนดังนี้
```
x_d = (x1 * 0.0174) - 0.2400
y_d = (y1 * 0.0174) - 1.7456
D = 12742 * arcsin(sqrt(sin^2((x_d)/2) + cos(0.24) * cos(x1 * 0.0174) * sin^2((y_d)/2)))
```
โดยนักศึกษาสามารถใช้คำสั่งเหล่านี้ในได้
- arcsin() -> math.asin()
- sqrt() -> math.sqrt()
- sin() -> math.sin()
- cos() -> math.cos()

สุดท้ายแล้ว `magic_function` จะส่งค่า `D` เป็นทศนิยม 2 ตำแหน่ง กลับออกมา (ใช่ครับ... มันคือระยะห่างในหน่วยกิโลเมตรจากคณะ ICT)

์**Note:** นักศึกษาสามารถใช้ round(D,2) เพื่อ round ค่า D เป็นทศนิยม 2 ตำแหน่งได้

### การรับข้อมูล

***นักศึกษาสามารถใช้โค้ดจาก itds-lab10-magic-function-retrival มาเขียนเพิ่ม/แก้ไขได้***

โปรแกรมใช้ **loop** เป็นจำนวน `num1` รอบ ในการเก็บผลลัพธ์จาก `magic_function` ที่ได้ประมวลผลล่วงหน้ามาแล้ว
โดยผลลัพธ์ของ `magic_function` จะถูกรับมาในรูปแบบตัวเลข 3 จำนวน
1. จำนวนทศนิยม 2 ตำแหน่ง ระบุค่าบนแกน x1
2. จำนวนทศนิยม 2 ตำแหน่ง ระบุค่าบนแกน y1
3. จำนวนทศนิยม ระบุผลลัพธ์ของ `magic_function`
โดยข้อมูลทั้ง 3 จะถูกแยกจากกันด้วยการขึ้นบรรทัดใหม่

จากนั้น สร้าง Tuple `(x1,y1)` เพื่อใช้เป็น key สำหรับ dictionary `magic_results` และใช้ผลลัพธ์ของ `magic_function` เป็น value

### การค้นหาข้อมูล คำนวณผลเพิ่ม และการแสดงผล
โปรแกรมจะใช้ **loop** เป็นจำนวน `num2` รอบ ในแต่ละรอบจะรับค่ามาในรูปแบบตัวเลข 3 จำนวน
1. จำนวนทศนิยม 2 ตำแหน่ง ระบุค่าบนแกน x
2. จำนวนทศนิยม 2 ตำแหน่ง ระบุค่าบนแกน y
3. จำนวนทศนิยม z

ในแต่ละชุดตำแหน่ง และค่าทศนิยมให้แสดงผลดังนี้
* print "Precisely" เมื่อ z **ตรงกับ** ผลลัพธ์จาก `magic_function` ที่คำนวณไว้ล่วงหน้า
* print "Diff by: " + (ผลลัพธ์จาก `magic_function` - z) เมื่อ z **ไม่ตรงกับ** ผลลัพธ์จาก `magic_function` ที่คำนวณไว้ล่วงหน้า
* print "New target " + (ผลลัพธ์จาก `magic_function`) + " km away" เมื่อตำแหน่ง `(x,y)` ไม่อยู่ในการประมวลผลล่วงหน้า (ไม่มีตำแหน่งดังกล่าวใน `magic_results`) พร้อมทั้งเพิ่มค่าดังกล่าวใน dictionary
