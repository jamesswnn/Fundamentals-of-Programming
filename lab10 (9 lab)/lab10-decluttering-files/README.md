## Files Decluttering with Set

จงเขียนโปรแกรมเพื่อหาจำนวนไฟล์ทั้งหมด จำนวนไฟล์ที่ซ้ำกัน และชื่อไฟล์ที่ซ้ำกันระหว่าง 2 โฟลเดอร์

โปรแกรมใช้ **loop** เป็นจำนวน `num1` รอบ ในการรับชื่อไฟล์จากโฟลเดอร์แรก โดยชื่อไฟล์จะถูกแยกเป็นชื่อละหนึ่งบรรทัด

จากนั้นโปรแกรมใช้ **loop** เป็นจำนวน `num2` รอบ ในการรับชื่อไฟล์จากโฟลเดอร์ที่สอง โดยชื่อไฟล์จะถูกแยกเป็นชื่อละหนึ่งบรรทัด

**ข้อสำคัญ** ในการกรอกชื่อไฟล์ของแต่ละโฟลเดอร์ ผู้ใช้อาจกรอกชื่อไฟล์ซ้ำได้

หลังจากนั้นโปรแกรมจะคำนวน
* จำนวนไฟล์ทั้งหมดระหว่าง 2 โฟลเดอร์ หากมีชื่อไฟล์ซ้ำ ให้นับเป็น 1 ไฟล์
* จำนวนไฟล์ที่ซ้ำกันทั้งหมด
* ชื่อของไฟล์ที่ซ้ำ โดยจะแสดงผลตามลำดับตัวอักษร นักศึกษาสามารถใช้คำสั่ง `sorted(list)` เพื่อเรียงลำดับข้อมูลใน list (ที่แปลงมาจาก Set) ได้
* หากไม่มีไฟล์ซ้ำให้ print "No duplicated found..."

<hr>

**ตัวอย่างที่ 1:**

**Input:** 
```
3
a.pdf
b.pdf
c.pdf
2
a.pdf
d.pdf
```
**Expected output:** 
```
4
1
['a.pdf']
```
<hr>

**ตัวอย่างที่ 2:**

**Input:** 
```
5
a.pdf
b.pdf
a.pdf
c.pdf
d.pdf
3
checkpoint3.docx
score.xlsx
slide10.pptx
```
**Expected output:** 
```
7
0
No duplicated found...
```
