## Calculate the Distance
จงเขียนโปรแกรมเพื่อคำนวณระยะทางในหน่วยกิโลเมตร โดยรับค่า input เป็นอัตราเร็วเฉลี่ย (sp) ในกิโลเมตรต่อชั่วโมง (เช่น 80 กิโลเมตรต่อชั่วโมง) และจำนวนนาที (t) ที่เดินทาง (เช่น 45 นาที)
<hr>

**ตัวอย่างที่ 1:**

**Input:** `sp=100` และ `t=30` โดยพิมพ์ 100 และ 30 ตามลำดับ
```
100
30
```
**Expected output:** หลังจากโปรแกรมคำนวณแล้ว โปรแกรมควรแสดงผลลัพธ์เป็น 
```
50.0
```
<hr>

**ตัวอย่างที่ 2:**

**Input:** `sp=80` และ `t=150` โดยพิมพ์ 80 และ 150 ตามลำดับ
```
80
150
```
**Expected output:** หลังจากโปรแกรมคำนวณแล้ว โปรแกรมควรแสดงผลลัพธ์เป็น
```
200.0
```
