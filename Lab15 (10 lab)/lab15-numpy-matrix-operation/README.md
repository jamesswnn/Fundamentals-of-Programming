# Lab 15: การคำนวณเมทริกซ์จากไฟล์ด้วย NumPy

ภายในโฟลเดอร์ `data/` มีไฟล์ข้อมูลเมทริกซ์อยู่ 8 ไฟล์ นักศึกษาต้องเขียนโปรแกรมใน `main.py` เพื่อรับชื่อไฟล์จาก standard input จำนวน 3 บรรทัด แล้วใช้ Python file I/O และ NumPy อ่านเมทริกซ์ `A`, `B` และ `C` ตามลำดับ

จากนั้นให้ตรวจสอบว่าเมทริกซ์ทั้งสามมีขนาดที่สามารถคำนวณตามสมการต่อไปนี้ได้หรือไม่

```python
(A + B) @ C
```

เครื่องหมาย `@` หมายถึง matrix multiplication ใน NumPy

## ข้อมูลนำเข้า

standard input ประกอบด้วยชื่อไฟล์ภายในโฟลเดอร์ `data/` จำนวน 3 บรรทัด สำหรับเมทริกซ์ `A`, `B` และ `C` ตามลำดับ เช่น

```text
matrix_01.txt
matrix_02.txt
matrix_03.txt
```

ไฟล์ข้อมูลแต่ละไฟล์มีเมทริกซ์เพียง 1 ตัว และไม่มีบรรทัดระบุขนาดของเมทริกซ์ แต่ละบรรทัดแทนข้อมูล 1 แถว โดยทุกบรรทัดในไฟล์เดียวกันมีจำนวนค่าเท่ากันเสมอ ตัวอย่างไฟล์:

```text
1 2 3
4 5 6
```

## ข้อมูลส่งออก

- หากไม่สามารถคำนวณได้ ให้แสดง shape ของ `A`, `B` และ `C` ก่อน ตามรูปแบบนี้

```text
A: <shape ของ A>
B: <shape ของ B>
C: <shape ของ C>
```

- หากสามารถคำนวณ `A + B` และ `(A + B) @ C` ได้ ให้แสดงผลลัพธ์ของ `(A + B) @ C` โดยใช้ `print()` กับ NumPy array โดยตรง
- หากไม่สามารถคำนวณได้ ให้แสดงข้อความต่อไปนี้หลังจากแสดง shape ทั้งสามบรรทัด

```text
Invalid matrix dimensions
```

## เงื่อนไข

1. ต้อง import และใช้ `numpy` เพื่อสร้างและคำนวณเมทริกซ์
2. ต้องอ่านข้อมูลจากไฟล์ทั้ง 3 ไฟล์ด้วย `open()` หรือ `with open(...)`
3. `A + B` ทำได้เมื่อ `A` และ `B` มี shape เท่ากัน
4. `(A + B) @ C` ทำได้เมื่อจำนวนคอลัมน์ของ `A + B` เท่ากับจำนวนแถวของ `C`
5. หาก dimension ไม่ถูกต้อง ต้องพิมพ์ `A.shape`, `B.shape` และ `C.shape` ก่อนแสดงข้อความผิดพลาด
6. ห้าม hard-code คำตอบหรือข้อมูลจากไฟล์ใดไฟล์หนึ่ง

## ตัวอย่าง

**ตัวอย่างที่ 1: สามารถคำนวณ `(A + B) @ C` ได้**

**Input**

```text
matrix_01.txt
matrix_02.txt
matrix_03.txt
```

**Output**

```text
[[ 41  52]
 [ 83 106]]
```

คำอธิบาย: `A.shape == (2, 3)` และ `B.shape == (2, 3)` จึงคำนวณ `A + B` ได้ จากนั้น `(A + B).shape == (2, 3)` มี 3 คอลัมน์ และ `C.shape == (3, 2)` มี 3 แถว จึงคำนวณ `(A + B) @ C` ได้ ผลลัพธ์มี shape เป็น `(2, 2)`

**ตัวอย่างที่ 2: ไม่สามารถคำนวณ `A + B` ได้**

**Input**

```text
matrix_01.txt
matrix_03.txt
matrix_05.txt
```

**Output**

```text
A: (2, 3)
B: (3, 2)
C: (2, 2)
Invalid matrix dimensions
```

คำอธิบาย: `A.shape == (2, 3)` แต่ `B.shape == (3, 2)` ซึ่งมี dimension ไม่เท่ากัน จึงไม่สามารถคำนวณ `A + B` และ `(A + B) @ C` ได้

**ตัวอย่างที่ 3: คำนวณ `A + B` ได้ แต่ไม่สามารถคำนวณ `(A + B) @ C` ได้**

**Input**

```text
matrix_05.txt
matrix_06.txt
matrix_03.txt
```

**Output**

```text
A: (2, 2)
B: (2, 2)
C: (3, 2)
Invalid matrix dimensions
```

คำอธิบาย: `A.shape == (2, 2)` และ `B.shape == (2, 2)` จึงคำนวณ `A + B` ได้ และ `(A + B).shape == (2, 2)` อย่างไรก็ตาม `C.shape == (3, 2)` มี 3 แถว ขณะที่ `(A + B)` มี 2 คอลัมน์ จึงไม่สามารถคำนวณ `(A + B) @ C` ได้
