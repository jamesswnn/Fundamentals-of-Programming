# Lab 15: ค้นหาจำนวนผู้โดยสาร Titanic ด้วย Pandas

จงเขียนโปรแกรมใน `main.py` เพื่ออ่านข้อมูลผู้โดยสารจากไฟล์ `data.csv` ด้วย Pandas แล้วนับจำนวนผู้โดยสารที่ตรงกับเงื่อนไขอายุและสถานะการรอดชีวิตที่ผู้ใช้ระบุ

## ข้อมูลนำเข้า

standard input มี 3 บรรทัดตามลำดับดังนี้

1. อายุขั้นต่ำ (`min_age`)
2. อายุสูงสุด (`max_age`)
3. สถานะการรอดชีวิต (`survived`) โดย `1` หมายถึงรอดชีวิต และ `0` หมายถึงไม่รอดชีวิต

แต่ละบรรทัดอาจเป็น `-` ซึ่งหมายถึงไม่ใช้เงื่อนไขนั้นในการค้นหา

## การเลือกข้อมูล

เริ่มต้นจากผู้โดยสารทุกคนใน `data.csv` แล้วใช้เฉพาะเงื่อนไขที่ผู้ใช้ระบุ

- หาก `min_age` ไม่ใช่ `-` ให้เลือกผู้โดยสารที่มี `Age` มากกว่าหรือเท่ากับ `min_age`
- หาก `max_age` ไม่ใช่ `-` ให้เลือกผู้โดยสารที่มี `Age` น้อยกว่าหรือเท่ากับ `max_age`
- หาก `survived` ไม่ใช่ `-` ให้เลือกผู้โดยสารที่มีค่าในคอลัมน์ `Survived` เท่ากับค่านั้น

เมื่อมีมากกว่าหนึ่งเงื่อนไข ผู้โดยสารต้องตรงตามทุกเงื่อนไขที่ระบุ

## ข้อมูลส่งออก

แสดงจำนวนผู้โดยสารที่ตรงกับเงื่อนไข เป็นจำนวนเต็มเพียง 1 บรรทัด



## ตัวอย่าง

**ตัวอย่างที่ 1: ระบุครบทุกเงื่อนไข**

**Input**

```text
20
40
1
```

**Output**

```text
208
```

คำอธิบาย: เลือกผู้โดยสารที่มีอายุตั้งแต่ 20 ถึง 40 ปี และรอดชีวิต

**ตัวอย่างที่ 2: ไม่กำหนดอายุขั้นต่ำ**

**Input**

```text
-
18
0
```

**Output**

```text
69
```

คำอธิบาย: เลือกผู้โดยสารที่มีอายุไม่เกิน 18 ปี และไม่รอดชีวิต

**ตัวอย่างที่ 3: ไม่กำหนดเงื่อนไข**

**Input**

```text
-
-
-
```

**Output**

```text
891
```

คำอธิบาย: ไม่มีเงื่อนไข จึงนับผู้โดยสารทุกคนในไฟล์
