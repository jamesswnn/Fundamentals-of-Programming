## Finding Primes

จงเขียนโปรแกรมที่จะค้นหาจำนวนเฉพาะ (Prime numbers) ที่มีค่าน้อยกว่า `n`

โดยโปรแกรมจะมีการเรียกใช้ function ที่ชื่อว่า `is_prime` ที่รับ 1 parameter คือ `num` และ return ค่า `True` หาก `num` เป็นจำนวนเฉพาะ

### การทำงานของโปรแกรม
โปรแกรมจะเริ่มจากการสร้าง list โดยใช้ชื่อว่า `primes` ที่มีค่า 2 เป็นข้อมูลใน list

จากนั้น โปรแกรมจะรับค่าจำนวนเต็ม `n` (n>2) และวนลูปตั้งแต่ 3 ถึง n (รวมค่า n)

ในแต่ละรอบ โปรแกรมจะเรียกฟังก์ชั่น `is_prime` เพื่อเช็คว่าค่าในรอบนั้นเป็นจำนวนเฉพาะหรือไม่
- หากเป็นจำนวนเฉพาะ (`is_prime` return `True`) ให้เก็บค่านั้นใน list `primes`
- หากไม่ใช่จำนวนเฉพาะ ให้ข้ามไปเลขถัดไป

เมื่อโปรแกรมวนลูปครบแล้ว ให้ใช้คำสั่ง `print(primes)` เพื่อแสดงค่าจำนวนเฉพาะที่น้อยกว่าหรือเท่ากับ `n`

### การทำงานของ `is_prime`
ฟังก์ชั่น `is_prime` จะรับ parameter คือ `num` และเรียกใช้ list `primes` ที่เป็นตัวแปร global

จากนั้น ฟังก์ชั่นจะเข้าถึงข้อมูลใน list `primes` โดยที่
- หากมีข้อมูลใดข้อมูลหนึ่งที่หาร `num` ลงตัว แสดงว่า `num` ไม่ใช่จำนวนเฉพาะ
    - ฟังก์ชั่น `is_prime` จะ return `False` หาก `num` ไม่ใช่จำนวนเฉพาะ
- หาก **ไม่มี** ข้อมูลใดข้อมูลหนึ่งที่หาร `num` ลงตัว แสดงว่า `num` เป็นจำนวนเฉพาะ
    - ฟังก์ชั่น `is_prime` จะ return `True` หาก `num` เป็นจำนวนเฉพาะ

**ข้อสังเกต** ฟังก์ชั่น `is_prime` จะเรียกใช้ตัวแปร `primes` แต่ไม่มีการเปลี่ยนแปลงข้อมูลที่อยู่ใน list

**ตัวอย่างที่ 1:**
**Input:**  
```
10
```
**Expected output:** 
```
[2, 3, 5, 7]
```
