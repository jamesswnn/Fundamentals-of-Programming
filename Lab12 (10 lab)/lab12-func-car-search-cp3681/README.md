# โปรแกรมค้นหาข้อมูลรถยนต์ด้วยเงื่อนไขแบบรวม (Functional Programming)

## วัตถุประสงค์

ให้นักศึกษาเขียนโค้ดเติมเต็มฟังก์ชัน search_car() เพื่อค้นหา ID ของรถยนต์ที่ตรงตาม ทุกเงื่อนไข ที่กำหนดมาพร้อมกัน (เงื่อนไขทั้งหมดเป็นแบบ AND) และเรียนรู้การจัดการ Argument แบบยืดหยุ่นด้วย **kwargs

ข้อบังคับสำคัญในการให้คะแนน:

1. ในการค้นหา Brand, Model, และ Year ต้อง ใช้ข้อมูลจากพารามิเตอร์ **kwargs (key/value pairs) เท่านั้น
2. ห้าม อ้างอิงถึงตัวแปร Global ที่รับ Input มาโดยตรง (เช่น brand_input, model_input) โดยเด็ดขาด หากฝ่าฝืนข้อนี้จะได้ 0 คะแนน
3. ฟังก์ชันต้องคืนค่าเป็น List ของ ID รถยนต์ (integer) เท่านั้น เช่น [1, 9]

## โครงสร้างการเรียกใช้ฟังก์ชัน (Output 4 บรรทัด)

นักศึกษาต้องทำให้ฟังก์ชัน `search_car` สามารถกรองข้อมูลตามเงื่อนไขราคา (min_price, max_price) ได้เสมอ และกรองตามเงื่อนไขใน **kwargs ที่ถูกส่งมาเท่านั้น**

```python
print(search_car(cars, min_price, max_price, brand=brand_input))
print(search_car(cars, min_price, max_price, model=model_input))
print(search_car(cars, min_price, max_price, year=year_input))
print(search_car(cars, min_price, max_price, brand=brand_input, model=model_input, year=year_input))
```
