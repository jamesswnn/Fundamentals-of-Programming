## Simplify Total Damage Calculation

ให้นักศึกษาจินตนาการถึงเกมส์ที่มีการต่อสู้ระหว่างสองทีม 

จงเขียนฟังก์ชั่น และเรียกใช้ฟังก์ชั่นนั้น เพื่อคำนวนค่าความเสียหายที่นักศึกษาทำได้ระหว่างโจมตีคู่ต่อสู้

โดยค่าความเสียหายที่นักศึกษาสร้างได้ จะประกอบด้วย
- สกิล Q - Array ของเลขจำนวนเต็ม
- สกิล E - เลขจำนวนเต็ม
- สกิล R - เลขจำนวนเต็ม

นอกจากนี้ ความเสียหายที่นักศึกษาสร้างได้ จะได้รับผลกระทบจาก
- Buff - เลขจำนวนเต็ม -> เปอร์เซ็นต์การเพิ่มพลังโจมตีของตัวละคร
- Resistance - เลขจำนวนเต็ม -> เปอร์เซ็นต์การป้องกันของศัตรู
- Addition - เลขจำนวนเต็ม -> ค่าอื่นๆ ที่ช่วยเพิ่มพลังโจมตี

การคำนวณค่าความเสียหายทั้งหมดที่นักศึกษาสร้างได้ จะเป็นไปตามสูตรด้านล่างนี้:
```
Total_Damage 
 = ((พลังโจมตีทั้งหมด * เปอร์เซ็นต์ Buff) * เปอร์เซ็นต์ Resistance) + Addition
 = (((sum([Q]) + E + R) * (100+Buff)/100) * (100-Resist)/100) + Addition
```

### ลำดับการรับข้อมูล
```
Q
q_1
q_2
...
q_Q
E
R
Buff
Resistance
Addition
```
**หมายเหตุ:** 
- สามารถสมมติได้ว่าผู้ใช้จะ input ตัวเลขจำนวนเต็มบวกเท่านั้นสำหรับ `Q`, `q_x`, `E`, และ `R` 
- หากไม่มีค่า `Buff`, `Resistance`, `Addition` ค่าเหล่านี้จะถูกแทนที่ด้วยเครื่องหมาย `-` ใน input (ดูตัวอย่างที่ 2)
