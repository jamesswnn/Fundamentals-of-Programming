## Search Frequency of a Number

จงเขียนโปรแกรมที่รับตัวเลข `n` จำนวน มาเก็บไว้ใน list `nums_list` โดยใช้ **loop** และ รับค่าตัวเลข `search` เพื่อนำไปค้นหาใน `nums_list` และนับจำนวนความถี่

โปรแกรมจะมี function `frequency` ซึ่งมี 2 parameters ได้แก่ list `nums_list` และตัวเลข `search` ซึ่งจะ return จำนวนครั้ง (ความถี่) ที่ตัวเลข `search` ถูกพบใน list `nums_list`

**หมายเหตุ:** 
สามารถสมมติได้ว่า `n` เป็นตัวเลขจำนวนเต็มบวกเท่านั้น และ input สำหรับ `nums_list` และ `search` จะเป็นข้อมูลตัวเลขเท่านั้น
<hr>

**ตัวอย่างที่ 1:**
**Input:** `n=6`, `nums_list = [1, 2, 3, 4, 4, 4]`, และ `search=4`
```
6
1
2
3
4
4
4
4
```
**Expected output:** โปรแกรมจะค้นหาตัวเลข `search=4` ใน `nums_list` ซึ่งมีความถี่จำนวน 3 ครั้ง 
```
3
```


<hr>

**ตัวอย่างที่ 2:**
**Input:** `n = 3`, `nums_list = [1,1,2]`, และ `search=1`
```
3
1
1
2
1
```
**Expected output:** โปรแกรมจะค้นหาตัวเลข `search=1` ใน `nums_list` ซึ่งมีความถี่จำนวน 2 ครั้ง 
```
2
```

**ตัวอย่างที่ 3:**

```
42
```
**Expected output:** โปรแกรมจะค้นหาตัวเลข `search=42` ใน `nums_list` ซึ่งมีความถี่จำนวน 0 ครั้ง 
```
0
```
