# โจทย์: ยอดน้ำหนักไอเท็มในกระเป๋าผู้เล่น

ให้เขียนโปรแกรมคำนวณ “ยอดน้ำหนักรวมของไอเท็มแบบไม่ซ้ำ” ของผู้เล่นแต่ละคน โดย
- มีพจนานุกรม **ไอเท็ม → น้ำหนัก**
- มีพจนานุกรม **ผู้เล่น → เซ็ตของไอเท็มที่ถือ** (หนึ่งผู้เล่นถือไอเท็มชนิดหนึ่งได้อย่างน้อย 0 หรือ 1 ชิ้นเท่านั้น)
- บรรทัดการมอบไอเท็ม (assignment) อาจซ้ำกันได้ แต่ต้องนับไอเท็มชนิดนั้นเพียงครั้งเดียวต่อผู้เล่น (จึงควรใช้ `set`)

> สมมติฐาน: ชื่อผู้เล่นและชื่อไอเท็มที่ปรากฏในส่วน assignment **มีอยู่ในพจนานุกรมเสมอ** ไม่ต้องตรวจสอบกรณีพลาดหรือข้อมูลไม่ตรง

---

## รูปแบบข้อมูลเข้า (input)
อินพุตทั้งหมดเป็น **ตัวอักษร/ตัวเลขทีละค่า ต่อหนึ่งบรรทัด** 

```
P
I
A
(player_1_name)
(player_2_name)
...
(player_P_name)
(item_1_name)
(item_1_weight)
(item_2_name)
(item_2_weight)
...
(item_I_name)
(item_I_weight)
(assign_1_player_name)
(assign_1_item_name)
(assign_2_player_name)
(assign_2_item_name)
...
(assign_A_player_name)
(assign_A_item_name)
```

คำอธิบาย:
- บรรทัดที่ 1: `P` จำนวนผู้เล่น 
- บรรทัดที่ 2: `I` จำนวนไอเท็ม
- บรรทัดที่ 3: `A` จำนวนบรรทัด assignment 
- ต่อไป `P` บรรทัด: ชื่อผู้เล่นตามลำดับที่ต้องการให้พิมพ์ผลลัพธ์
- ต่อไป `2*I` บรรทัด: ชื่อไอเท็มและน้ำหนักสลับกัน (ชื่อ 1 บรรทัด, น้ำหนัก 1 บรรทัด)
- ต่อไป `2*A` บรรทัด: assignment ทีละคู่ (ผู้เล่น 1 บรรทัด, ไอเท็ม 1 บรรทัด)

ข้อกำหนด:
- ชื่อ (ผู้เล่น/ไอเท็ม) ไม่มีช่องว่าง
- น้ำหนักเป็นจำนวนเต็มไม่ลบ
- ผู้เล่นหนึ่งคนถือไอเท็มชนิดเดิมซ้ำหลายครั้ง ให้คิดเป็น **ครั้งเดียว** (จึงควรเก็บเป็น `set`)
- ให้พิมพ์ผลลัพธ์ตาม **ลำดับผู้เล่นที่รับเข้ามา**

**Hint:**  
แนะนำให้นักศึกษาเก็บรายชื่อผู้เล่นไว้ใน list เช่น `players = [...]`  
เพื่อใช้ลำดับนี้ในการพิมพ์ผลลัพธ์สุดท้าย

---

## รูปแบบข้อมูลออก (output)
พิมพ์ `P` บรรทัด:
```
<player_name> <total_weight_of_unique_items>
```

---

## ตัวอย่างที่ 1

**input**
```
1
3
4
alice
sword
5
apple
1
ring
2
alice
sword
alice
apple
alice
ring
alice
ring
```

**output**
```
alice 8
```

**คำอธิบาย**
- พจนานุกรมน้ำหนัก: `{sword:5, apple:1, ring:2}`
- alice ถือ {sword, apple, ring} → 5+1+2 = 8  
(บรรทัด `alice ring` ซ้ำจึงไม่นับเพิ่ม)

```
3
4
8
alice

cy
sword

7

1

2
alice
sword
alice

alice

```

**output**
```

```

**คำอธิบาย**
- พจนานุกรมน้ำหนัก: `{sword:5, shield:7, apple:1, ring:2}`
- alice ถือ {sword, shield} → 5+7 = 12  
- bob ถือ {apple, ring} → 1+2 = 3  
- cy ถือ {sword, ring} → 5+2 = 7  
(บรรทัด assignment ซ้ำไม่ต้องนับเพิ่ม)
