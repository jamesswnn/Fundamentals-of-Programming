## Remove Negative Numbers from the List

จงเขียนโปรแกรมที่รับตัวเลข `n` จำนวน มาเก็บไว้ใน list `nums_list` โดยใช้ **loop** 

จากนั้นใช้ built-in function `filter` และ `lambda` เพื่อ return list ผลลัพธ์ที่ไม่มีจำนวนลบอยู่แล้ว

**หมายเหตุ:** 
สามารถสมมติได้ว่า `n` เป็นตัวเลขจำนวนเต็มบวกเท่านั้น และตัวเลข input สำหรับ `nums_list` จะเป็นตัวเลขเท่านั้น

<hr>

**ตัวอย่างที่ 1:**
**Input:** `n = 5` และ `nums_list = [1,2,
-1,-2, 3]` 
```
5
1
2
-1
-2
3
```
**Expected output:** โปรแกรมจะแสดงค่าใน list ที่ไม่มีจำนวนลบ ดังต่อไปนี้
```
[1, 2, 3]
```

<hr>

**ตัวอย่างที่ 2:**
**Input:** `n = 3` และ `nums_list = [-1,-2,
-3]` 
```
3
-1
-2
-3
```
**Expected output:** โปรแกรมจะแสดงค่าใน list ที่ไม่มีจำนวนลบ ดังต่อไปนี้
```
[]
```

**ตัวอย่างที่ 3:**
**Input:** `n = 6` และ `nums_list = [9,-9,5,-5,4,-4]` 
```
6
9
-9
5
-5
4
-4
```
**Expected output:** โปรแกรมจะแสดงค่าใน list ที่ไม่มีจำนวนลบ ดังต่อไปนี้
```
[9, 5, 4]
```
