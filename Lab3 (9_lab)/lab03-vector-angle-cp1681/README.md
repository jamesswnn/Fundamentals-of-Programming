# Q4: ตรวจสอบมุมระหว่างเวกเตอร์ 2 เส้น (Vector Angle Classification)

โปรแกรมนี้รับพิกัดจุด 3 จุดในระนาบ 2 มิติ (x1, y1), (x2, y2), (x3, y3)
และตรวจสอบประเภทของมุมที่เกิดขึ้นที่จุด (x1, y1) ระหว่างเวกเตอร์

- $v1 = (x2 - x1, y2 - y1) = (a, b)$
- $v2 = (x3 - x1, y3 - y1) = (c, d)$

---

## สูตรที่ใช้

1. **Dot Product (จุดคูณเวกเตอร์):**
   $$
   v1 \cdot v2 = a \times c + b \times d
   $$
2. **Length of Vector (ความยาวเวกเตอร์):**
   $$
   ||v1|| = \sqrt{a^2 + b^2}
   $$
   $$
   ||v2|| = \sqrt{c^2 + d^2}
   $$

3. **Cosine of Angle (ค่า Cosine ของ มุม):**
   $$
   \cos \theta = \frac{v1 \cdot v2}{||v1|| \cdot ||v2||}
   $$

---

## เกณฑ์การจัดประเภทมุม

- ถ้า $\cos \theta > 0$ จัดเป็น **ACUTE** (มุมแหลม)
- ถ้า $\cos \theta = 0$ จัดเป็น **RIGHT** (มุมฉาก)
- ถ้า $\cos \theta < 0$ จัดเป็น **OBTUSE** (มุมป้าน)

---

## Input Format

รับค่าจำนวนจริง 6 ค่า (บรรทัดละ 1 ค่า):

- x1
- y1
- x2
- y2
- x3
- y3

## Output Format

1. ค่า cos(θ) ปัดทศนิยม 2 ตำแหน่ง (ใช้ `round(c, 2)`)
2. ประเภทของมุม (`ACUTE`, `RIGHT`, หรือ `OBTUSE`)

### Expected Input/Output

| input (จากแป้นพิมพ์) | output (ทางจอภาพ) |
|------------------------|--------------------|
| 0<br>0<br>1<br>0<br>0<br>1 | 0.0<br>RIGHT |
| 0<br>0<br>1<br>0<br>1<br>1 | 0.71<br>ACUTE |
| 0<br>0<br>-1<br>0<br>1<br>1 | -0.71<br>OBTUSE |
| 2<br>2<br>5<br>6<br>-2<br>5 | 0.0<br>RIGHT |
| 0<br>0<br>2<br>0<br>5<br>0 | 1.0<br>ACUTE |


คำอธิบายตัวอย่างที่ 4

- จุดที่สนใจคือ (x1, y1) = (2, 2)
- จุดที่สอง (x2, y2) = (5, 6)
- จุดที่สาม (x3, y3) = (-2, 5)

1. สร้างเวกเตอร์
   $$v1 = (x2 - x1, y2 - y1) = (5 - 2, 6 - 2) = (3, 4)$$
   $$v2 = (x3 - x1, y3 - y1) = (-2 - 2, 5 - 2) = (-4, 3)$$
2. คำนวณ dot product
   $$v1 \cdot v2 = (3)(-4) + (4)(3)
   = -12 + 12
   = 0
   $$
3. คำนวณความยาวเวกเตอร์
   $$||v1|| = sqrt(3^2 + 4^2) = sqrt(9 + 16) = 5$$
   $$||v2|| = sqrt((-4)^2 + 3^2) = sqrt(16 + 9) = 5$$
4. คำนวณค่า $\cos \theta$
   $$ \cos \theta = \frac{(v1 · v2)}{(||v1|| * ||v2||)}
   = 0 / (5 * 5)
   = 0.0
   $$
