# Q4: ICTxDST Programming Competition

ในการแข่งขันกีฬาประจำคณะ ICT ชมรม dev club ของคณะได้จัดการแข่งขันการเขียนโปรแกรม (ICTxDST Programming Competition) ขึ้น โดยให้ทีมผู้เข้าแข่งขันทำโจทย์และส่งผลลัพธ์เข้ามาตรวจสอบ เมื่อผ่าน test cases ทั้งหมดแล้ว ทีมผู้เข้าแข่งขันจะได้รับลูกโป่ง 1 ลูกต่อ 1 ข้อ เมื่อสิ้นสุดการแข่งขันจะประกาศผู้ชนะจากลำดับ

- รองชนะเลิศอันดับ 2
- รองชนะเลิศอันดับ 1
- ชนะเลิศ

## คำสั่ง

ให้นักศึกษาเขียนโปรแกรมประมวลผลจำนวนลูกโป่งและประกาศจำนวนลูกโป่งของทีมที่ชนะตามลำดับข้างต้น

ให้สมมติว่าไม่มีทีมที่ได้รางวัลทีมไหนที่ได้จำนวนลูกโป่งเท่ากัน และมีทีมมากกว่า 4 ทีมเสมอ

### Input

รับค่าจำนวนเต็มจำนวนลูกโป่งของแต่ละทีม จนกระทั่งมีค่า `-1` เข้ามาเพื่อหยุดการรับค่า

### Output

```plaintext
- X
- Y
- Z
```

โดยที่ X, Y, Z เป็นจำนวนลูกโป่งของทีมที่ได้รับรางวัล แต่ละลำดับ

## Hint

นักศึกษาสามารถใช้ `.sort()` ได้
