## Create a Dictionary for Student Grade
จงเขียนโปรแกรมเพื่อรับ input `name` และ `grade` ('a', 'b', 'c', 'd') มาเป็นข้อมูลที่ถูกเก็บใน dictionary `student` โดยข้อมูลทั้งหมดจะเป็นตัวอักษรพิมพ์เล็ก (lower case) 

dictionary `student` นั้นประกอบด้วย `name` และ `grade` keys

ถ้า `grade` มีค่าเป็น a โปรแกรมจะเปลี่ยน key `grade` เป็นตัวหนังสือพิมพ์ใหญ่ (upper case)

สุดท้ายโปรแกรมจะแสดงผลลัพธ์ print dictionary ออกมา

<hr>

**ตัวอย่างที่ 1:**

**Input:** ผู้ใช้ `name` และ `grade`
```
thai
b
```
**Expected output:** 
```
{'name': 'thai', 'grade': 'b'}
```
<hr>

**ตัวอย่างที่ 2:**

**Input:** ผู้ใช้ `name` และ `grade``
```
kitty
a
```
**Expected output:**
```
{'name': 'kitty', 'GRADE': 'a'}
```
<hr>

**ตัวอย่างที่ 3:**

**Input:** ผู้ใช้ `name` และ `grade``
```
Hit
c
```
**Expected output:** 
```
{'name': 'Hit', 'grade': 'c'}
```
